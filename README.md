# AVC FOODS Website

Static website for AVC FOODS.

## GitHub Pages Upload

1. ZIP ko pehle **Extract All** karein. ZIP ke andar se `index.html` direct open na karein.
2. Create a new GitHub repository.
3. Extracted folder ke andar ka `index.html` aur poora `assets` folder upload karein.
   `assets` folder upload kiye bina photos aur banners nahi dikhenge.
4. Open repository Settings.
5. Go to Pages.
6. Select Deploy from branch.
7. Choose `main` branch and `/root`.
8. Save.

After a few minutes, GitHub will show the public website link.
